ONG Esperança

Sobre o projeto

O ONG Esperança é um projeto web desenvolvido para apresentar a organização, seus projetos sociais e disponibilizar uma área de cadastro.

Tecnologias utilizadas

O projeto foi desenvolvido utilizando HTML5 para a estrutura das páginas, CSS3 para a estilização e JavaScript para comportamentos e interações da aplicação.

Estrutura do projeto

O projeto contém páginas HTML para as áreas de início, projetos e cadastro, além de arquivos CSS, JavaScript e imagens utilizados no funcionamento e na apresentação do site.

Pré-requisitos

Para executar o projeto localmente, é necessário apenas um navegador web atualizado. Não são necessárias dependências externas ou instalação de pacotes.

Como executar

1. Baixe ou clone o repositório do projeto.
2. Extraia os arquivos, caso tenha realizado o download em formato ZIP.
3. Abra o arquivo "index.html" em um navegador.
4. Navegue pelas páginas do projeto utilizando o menu.

Por ser um projeto web estático, não há etapa de build ou comando de instalação de dependências.

Versionamento

O versionamento do projeto é realizado com Git e GitHub. Foi utilizada a branch principal "main" e criada a branch "feature/organizacao-projeto" para organizar alterações. As Issues e a Milestone foram utilizadas para registrar e organizar as tarefas relacionadas ao projeto.
